# Pedra, Papel e Tesoura

Jogo de pedra, papel e tesoura contra o smartphone.

## O que o app faz

- O usuário escolhe pedra, papel ou tesoura e o app sorteia a jogada do smartphone.
- O placar conta vitórias, derrotas e empates.

Projeto da disciplina de **Desenvolvimento para Dispositivos Móveis (DDM)** — IFSP Campus Votuporanga.
